# My Portfolio

[View Live Portfolio](https://rithiha-ai-engineer-software-developer-portfolio.ai.studio/)

## Overview

This repository contains the source code for my personal portfolio website.

The portfolio provides a professional presentation of my technical work, with a focus on Artificial Intelligence, Machine Learning, Generative AI, software development, and data analytics.

The website is designed to provide recruiters, hiring managers, and collaborators with a concise view of my work and technical background.

* Responsive and modern portfolio design
* Professional profile and introduction
* Technical skills showcase
* Featured project presentation
* Project details with repository references
* Experience and education sections
* Certifications and achievements
* Contact and professional profile links
* Responsive layout for desktop, tablet, and mobile devices

## Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js
* npm

### Installation

Clone the repository and navigate to the project directory:

```bash
git clone https://github.com/Rithi-20/My-Portfolio.git
cd My-Portfolio
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local development URL shown in the terminal to view the portfolio.
